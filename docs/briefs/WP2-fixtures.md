# WP2 — Test fixtures with ground truth + STL checker + engine test harness (coder: Sonnet)

Read first: `docs/coding-rules.md`, `docs/contracts.md` (§2, §3, §4, §7, §21), `resources/skeleton.json`.

Goal: deterministic, **original** test characters and weapons, generated by a Blender script, each
with exact ground-truth JSON. Every later work package measures itself against these. Also a minimal
engine test harness and an STL checker.

Run everything with:
`"C:/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b --factory-startup --python-exit-code 1 -P <script> -- <args>`

## Files to create

- `engine/mpm/stlcheck.py`: numpy-only STL checker (no bpy); also runnable as

## Mesh construction

Use Blender's **Skin modifier** on an edge graph with vertices at the joints, then a Subdivision
Surface modifier at level 1, then apply both.
- Spine chain pelvis–spine0–chest–neck–head–head_top.
- Arms clav–shoulder–elbow–wrist; from the wrist, one branch to each finger's `_0` then `_1`, `_2`,
  `_tip`. Thumb: `thumb_0`, `_1`, `_2`, `_tip`.
- Legs pelvis–hip–knee–ankle–ball–toe.

Rigged fixtures:
- Bones follow the mesh joints in their own convention (a T-pose rest for Mixamo and Biped, A-pose for
  UE).
- Weights are deterministic: per vertex, the 2 nearest bone segments, weights ∝ 1/d⁴, normalised.
- The truth includes `mapping: {fixture bone name: canonical bone name | null}`. Twist and IK bones,
  `root` and `Bip01` map to null; metacarpals to null; end bones to null.

Texture (every humanoid except `dense`):
- Generate a 1024² height field H in numpy, seeded with 1234:
  - groove grid every 64 px, 3 px wide, depth −1.0
  - 40 round studs, radius 10 px, height +1.0, smoothstep edges
- Tangent-space normals from central differences with strength k = 2.0:
  `n = normalize(−k·dH/du, −k·dH/dv, 1)`, written in the **DirectX** convention (green flipped), as
  `<name>_n.png`.
- Base colour `<name>_d.png`: flat 0.6 grey.
- UVs: Smart UV Project (angle 66°, island margin 0.02) using `bpy.context.temp_override`.
- Material: Principled BSDF with a Normal Map node fed by the normal image (Non-Color).
- Save H as `<name>_height.npy` and record `normal_convention: "directx"` in the truth.
- FBX export with `path_mode='COPY'`, `embed_textures=True`.

## `engine/mpm/stlcheck.py`
Port this logic (numpy only):
- Read binary STL (80-byte header, uint32 count, records of 12 float32 + uint16).
- Merge vertices by exact coordinate (`np.unique(axis=0)`).
- Count edges used by exactly 1 face (open) and by more than 2 faces (non-manifold).
- Signed volume (divergence theorem).
- bbox dims and floor z.
- Sole contact area: triangles with `max z < floor + 0.1` (in file units, mm) and unit normal
  `z < −0.95`, split by triangle centroid x < 0 (R) / ≥ 0 (L).

`check(path) -> {"tris", "dims", "floor_z", "open_edges", "nonmanifold_edges", "volume", "sole_contact": {"L", "R"}}`.

## `tests/engine/run.py`
- Adds `<repo>/engine` and `<repo>/tests/engine` to `sys.path`.
- Discovers `tests/engine/test_*.py` (optionally filtered by a substring argument after `--`).
- Runs every module-level function named `test_*`. Each test gets a fresh scene
  (`bpy.ops.wm.read_factory_settings(use_empty=True)` before each).
- Prints `PASS name` / `FAIL name: <traceback>` and a summary, and exits with code 1 on any failure.
- Fixtures dir = env `MPM_FIXTURES` or `<repo>/fixtures/out`. If it's missing, generate the fixtures
  first by running `fixtures/generate.py` in-process.

## `tests/engine/test_fixtures.py` (acceptance)
- Every fixture's files and truth exist. `joints` has 68 entries, and every bone head/tail in
  skeleton.json is a joint.
- `apose` FBX re-imported with `bpy.ops.import_scene.fbx(automatic_bone_orientation=False)`:
  - single mesh, 0 non-manifold edges
  - every editable joint lies inside the mesh (ray-parity test along +X, −X, +Z: odd hit count)
- `yup_cm` imported with the default importer settings: its bbox height ≈ 1.80 m after import
  (the importer converts axes; record what you observe in the test output).
- Palm-normal sign rule (contracts §4): `apose` L palm normal x < 0, R x > 0; `tpose` L palm normal z < 0.
- Normal map round trip: recompute normals from `<name>_height.npy` and compare to the PNG decoded as
  DirectX; the mean absolute channel error is < 2/255.
- `stlcheck` on a 1 m cube STL you write in the test: 12 tris, 0 open, 0 non-manifold, volume 1.0.
- Rigged fixtures re-imported:
  - the bone names in the truth `mapping` all exist
  - every vertex has a non-zero total weight
